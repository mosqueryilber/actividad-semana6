El login en una aplicación permite identificar a un usuario antes de darle acceso a ciertas funciones o secciones del sistema. Esto ayuda a saber quién entra a la plataforma y qué acciones puede realizar. Algunas rutas deben estar protegidas porque pueden contener información privada, registros internos o herramientas que no deberían estar disponibles para cualquier persona. La autenticación también permite diferenciar entre usuarios normales y administradores. De esta forma se mejora la seguridad y el control del sistema. No se deben exponer públicamente contraseñas, documentos de identidad, teléfonos, direcciones, correos personales, tokens, claves de API ni ningún dato sensible de la comunidad.
